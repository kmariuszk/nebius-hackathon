Part 1 · Finding candidates (built today)

Part 1 is about recall: cast a wide net and don't lose anything. Nothing here judges whether a paper is actually good. It just collects, deduplicates and orders by cheap signals. The code is in discovery/, served as the papers MCP.

1 · One paper, many names

built discovery/discovery/store.py:37 · papers.py:16

Before anything else: the same paper arrives from different sources under different IDs. If we didn't fix that, every count and ranking after this would be wrong.

2 · Taking turns: merging ranked lists

built discovery/discovery/service.py:253 (_round_robin) · service.py:37 (search)

search(query) asks PubMed, OpenAlex and the web (Tavily) at the same time. Each answers with its own ranked list. How do you combine three lists when their scores mean different things?

3 · Expanding from seeds: counting links

built discovery/discovery/service.py:189 (_pubmed_links, the formula is on line 206)

Keywords miss papers that use different words. Seeds don't have that problem: a paper that cites your seed, is cited by it, or that PubMed calls "similar" is related however it's worded.

4 · Strategies vote

built discovery/discovery/service.py:57 (find_candidates, sort on line 100)

find_candidates(seeds) runs several independent strategies: the PubMed links from step 3, OpenAlex papers that cite the seeds, and Semantic Scholar recommendations. Then it combines them.

5 · The search agent drives the tools

built harness/harness/agents/search/agent.py (the done tool is on branch fix/search-agent-done) · the master agent that calls it is planned

Steps 1–4 are plain code. A small, fast model (Nemotron Lightning) decides which of them to call for one sub-query. It has a strict budget and only one way to stop.

The whole funnel

Every stage is cheaper per paper than the one after it, so the expensive model only sees the finalists.

How we'll know each stage earns its place (Concept.md, evaluation): rank a held-out set three ways (embeddings only, then embeddings plus Lightning verdicts, then both plus the Super VL rerank) and show the judges one table.
